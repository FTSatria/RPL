# DataQuest – Database Designer Adventure

**Media Pembelajaran Interaktif • SMK • Konsentrasi Keahlian Rekayasa Perangkat Lunak (RPL)**  
Perpaduan **Adventure Game** dan **Simulation Game** dengan alur bekerja nyata sebagai *Junior Database Designer* di perusahaan konsultan software.

---

## Cara Menjalankan Gim
Gim ini dirancang sebagai aplikasi web mandiri (**Zero Build / Zero Dependency**) yang dapat langsung dijalankan di perangkat Desktop, Tablet, maupun HP:
1. Buka langsung file **`index.html`** menggunakan browser modern (Google Chrome, Microsoft Edge, Firefox, Safari), atau unggah seluruh folder ke GitHub Pages / hosting sekolah.
2. Pada HP/Tablet, gunakan orientasi **Landscape (16:9)** agar area simulasi tampil optimal satu layar penuh tanpa scroll vertikal.
3. Untuk pengujian cepat oleh Guru/Evaluator ke scene tertentu:
   - Klik tombol **📊 Guru** di pojok kanan atas → klik **🔓 Mode Guru: Buka Semua 15 Scene**, atau
   - Tambahkan parameter URL, misalnya `index.html?scene=8` (ERD Builder) atau `index.html?scene=11` (SQL Workshop).

---

## Struktur 15 Scene Sesuai Storyboard & Design Collage
1. **Scene 01 – Opening (Dunia DataQuest)**: Orientasi awal dunia perusahaan konsultan software DataQuest.
2. **Scene 02 – Character Setup (Identitas Pemain)**: Pemilihan 6 avatar konsultan muda, nama pemain, dan peran.
3. **Scene 03 – Mission Briefing (Panggilan Proyek)**: Membuka surat **Order Work #001 (Sistem Informasi Perpustakaan)** dari Manajer Proyek.
4. **Scene 04 – Database Academy (Pengenalan Basis Data)**: Eksplorasi interaktif 4 komponen utama (*Data, Tabel, DBMS, Pengguna*) & Kuis Cepat.
5. **Scene 05 – Data Detective (Analisis Kebutuhan)**: Investigasi kebutuhan klien melalui *Drag & Drop* / klik bukti dan penyaringan data pengecoh.
6. **Scene 06 – Entity Architect (Identifikasi Entitas)**: Pengelompokan kartu atribut mentah ke Entitas (*Anggota, Buku, Petugas*) dengan koreksi langsung.
7. **Scene 07 – Key Master (Primary Key & Foreign Key)**: Penetapan PK, FK, dan penghubung relasi `1..N` antartabel.
8. **Scene 08 – ERD Architect (Membangun ERD)**: Kanvas *ERD Builder* interaktif untuk merancang Entitas, Relasi belah ketupat, dan Kardinalitas.
9. **Scene 09 – Table Engineer (Transformasi ERD)**: Transformasi diagram ERD menjadi skema Tabel Relasional dan tipe data SQL.
10. **Scene 10 – Normalization Lab (Normalisasi Database)**: Memecahkan puzzle bertahap **1NF → 2NF → 3NF** untuk mengeliminasi redundansi & anomali.
11. **Scene 11 – SQL Workshop (Implementasi Database)**: *SQL Playground* aman di browser untuk mengeksekusi `CREATE TABLE`, `INSERT`, `SELECT`, `UPDATE`, dan `DELETE`.
12. **Scene 12 – Boss Challenge (Final Project)**: Studi kasus mandiri **Order Work #002 (Sistem Informasi Kantin Sekolah)**.
13. **Scene 13 – Quality Assurance (Evaluasi Hasil)**: Pengujian 5 pilar QA, perbaikan temuan audit, dan pengiriman rancangan ke klien.
14. **Scene 14 – Achievement (Database Designer)**: Perayaan kelulusan, total XP, Level, 5 Badge, dan **Sertifikat Resmi siap cetak/PDF**.
15. **Scene 15 – Reflection Room (Refleksi Pembelajaran)**: Evaluasi diri, jurnal refleksi proyek, **Leaderboard Konsultan**, dan ekspor **Laporan Hasil Belajar Siswa (`.json`)**.
